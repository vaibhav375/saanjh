          Evidence · two seasons replayed on AWS · open API · code

          How we know it works

          Every image GK-2A took of Punjab and Haryana, 15 Oct – 30 Nov, in 2024 and 2025. Methods were tuned on 2024 and tested on 2025, a season they never saw — including the one place where Saanjh doesn't help.

          How it runs on AWS

          Event-driven and serverless, in us-east-1 next to NOAA's GK-2A bucket. The same Lambdas serve the live system and replay whole seasons.

          Live pipeline on AWS

          Last 24 hours · CloudWatch

            Every GK-2A image triggers NOAA's SNS topic → SQS → Lambda. Failed images go to a dead-letter queue; alarms page the operator by email.
